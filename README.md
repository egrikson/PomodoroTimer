# Помодоро

Таймер помодоро для Windows 11. Одно окно WPF, оформление по канонам Fluent Design:
подложка Mica, системный акцентный цвет, светлая и тёмная темы вслед за системой.

Устанавливать ничего не нужно — `Pomodoro.exe` весит около 70 КБ и работает на любой
Windows с .NET Framework 4.x (то есть на любой Windows 10 и 11 из коробки).

## Запуск

Скачайте [`Pomodoro.exe`](Pomodoro.exe) и запустите. Ярлык можно закрепить в меню «Пуск»
или на панели задач обычным способом.

## Тайминги

Переключатель вверху окна — три набора «работа / перерыв» в минутах:

| Набор | Работа | Перерыв |
| --- | --- | --- |
| 25 / 5 | 25 мин | 5 мин |
| 50 / 10 | 50 мин | 10 мин |
| 60 / 15 | 60 мин | 15 мин |

Фазы чередуются сами: после работы сразу начинается перерыв, после перерыва — новая
сессия. Во время перерыва кольцо становится зелёным. Точки под кольцом показывают
текущий цикл из четырёх, ниже — счётчик завершённых помидоров за сеанс.

## Будильник

Стандартные уведомления Windows тихие и зависят от звуковой схемы, поэтому сигнал
синтезируется прямо в приложении и играется через `SoundPlayer` на почти полной шкале
(пик −0,2 дБFS, RMS около −8 дБFS). Мелодии две, они различаются на слух:

| Событие | Сигнал |
| --- | --- |
| Конец фокуса | нисходящее трезвучие ми–до♯–ля, «можно отдохнуть» |
| Конец перерыва | настойчивый двойной писк и высокая нота, «подъём» |

Сигнал звонит по кругу, пока его не выключить, и сам замолкает через 30 секунд.
Глушится любым нажатием мыши или клавиши в окне. Кнопка с динамиком в заголовке
выключает будильник совсем. Параллельно мигает кнопка в панели задач.

Тембр набран из трёх гармоник — чистая синусоида на слух заметно глуше при той же
амплитуде. У каждой ноты скруглённая огибающая, иначе на стыках слышны щелчки.

## Управление

| Действие | Как |
| --- | --- |
| Старт / пауза | кнопка «Старт» или **Пробел** |
| Сброс текущей фазы | кнопка «Сбросить» или **R** |
| Пропустить фазу | кнопка «Пропустить» |
| Заглушить звонок | любой клик или клавиша в окне |
| Выключить будильник | кнопка с динамиком в заголовке |
| Поверх всех окон | кнопка-булавка в заголовке |
| Сменить подложку | кнопка с глазом: мика → акрил → сплошная |
| Переместить окно | перетащить за заголовок |
| Закрыть | крестик или **Esc** |

## Как это сделано

- Окно без системного заголовка (`WindowChrome`), но с расширенным на всю клиентскую
  область стеклом, поэтому DWM рисует настоящую подложку.
- Подложка — `DWMWA_SYSTEMBACKDROP_TYPE`: Mica по умолчанию, Acrylic и сплошная заливка
  по кнопке. Скруглённые углы и тёмная рамка тоже запрашиваются у DWM.
- Цвета — токены WinUI (`ControlFillColorDefault`, `ControlElevationBorderBrush`,
  `TextFillColorSecondary` и прочие). Акцент читается из `AccentPalette`: в тёмной теме
  берётся `SystemAccentColorLight2`, в светлой — `Dark1`, как это делает сама Windows.
- Отсчёт привязан к системному времени, а не к тикам таймера, поэтому пауза и сон
  компьютера не сбивают оставшееся время.

## Сборка из исходников

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

Скрипт рисует иконку, приводит исходники к UTF-8 с BOM и вызывает `csc.exe` из состава
.NET Framework. Ни Visual Studio, ни .NET SDK не требуются.

| Файл | Что это |
| --- | --- |
| `src/Program.cs` | логика таймера, чтение темы, вызовы DWM |
| `src/Alarm.cs` | синтез мелодий будильника в PCM |
| `src/ui.xaml` | разметка и стили; встраивается в exe как ресурс |
| `src/AssemblyInfo.cs` | название и версия сборки |
| `build.ps1` | генерация иконки и компиляция |

Исходники хранятся в UTF-8 с BOM — без него Windows PowerShell 5.1 и `csc.exe`
прочитают русский текст в кодировке ANSI и он превратится в кракозябры.
